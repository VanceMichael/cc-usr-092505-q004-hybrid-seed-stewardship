# 杂交稻制种受托与质量追溯

管理杂交稻制种合同、地块隔离、批次质量和匿名价格指数。

## 领域资料

`contracts/domain.schema.json` 记录共享资料结构，`fixtures/domain.json` 是不含真实个人信息的示例。参与方包括种业企业、制种受托人、县级管理人员、种子检验人员、质量放行人、联盟秘书处与抽查人员。

当前资料依据以下业务事实维护：

- 三明拥有多个国家级制种大县和大量种业企业
- 联盟发布新品种并建立受托人管理和分级认定制度
- 当地发布水稻制种价格指数并强调多性状协同育种

## 服务模块（`src/hybrid_seed_stewardship/`）

- `model.py`：不可变领域结构（角色、受托人等级区间、品种备案版本、合同版本、
  隔离区与地块、物料事件、检验、放行、替代纠正、成品袋、报价与指数）。
- `service.py`：`StewardshipService` 实现全部业务不变量：
  - 品种备案与受托合同**只追加版本**，历史版本不可改写；田间检查绑定到具体合同版本。
  - 收获、混样、加工、抽样、拆批、合批、包装严格**重量守恒**
    （消耗 = 产出 + 显式损耗）；不同亲本批次的种子禁止混合，地块与亲本谱系随批次传播。
  - 并行加工/抽样先**预约占用**数量，事件消耗必须与预约逐条对应，同一数量不可重复占用。
  - 花期冲突比较相邻隔离区（含秘书处登记的跨县相邻关系）的实际距离与隔离要求；
    花期冲突、气候风险、受托人资格变化、检验复核**只影响尚未放行的批次**。
  - 放行为独立角色，且不得是该批次的生产提交人；放行必须依据最新检验结论；
    已发布结论只能由**替代版本**纠正，原结论保留可溯。
  - `trace_package()` 支持抽查人员扫码查看成品袋的地块、亲本、全部加工事件、检验与放行。
  - 企业视图只暴露本企业合同下的批次，竞争者明细不可见；`total_weight_check()` 提供全库守恒自检。
- `index.py`：`IndexOffice` 编制匿名价格指数。报价逐道通过门槛
  （品种权覆盖期末、品种/备案一致、最小数量、价格区间、同期同企业去重），
  且通过报价来自不少于规定家数的企业才发布；发布结果只含升序匿名价格序列，
  `decision_of()` 可逐条追问某条报价进入或未进入当期指数的具体门槛与理由。

## 开发命令

- 运行测试：`python3 -m unittest discover -s tests -v`
- 编译或构建：`python3 -m compileall -q src/hybrid_seed_stewardship tests`

上述命令只读取仓库内文件，不连接外部业务服务。
